# Wording

These bands and steps are **starting defaults**. A quote, a history, or a prompt can move you off them. When it does, tag `[S]`, keep the quote, and list the departure for revision.

Use the midpoint of a band unless the quote pushes you to an edge (`more than`, `at least`, `up to`).

## Absolute phrases

| Phrase | Starting default |
|---|---|
| low single-digit | 1–3% |
| mid-single-digit | 4–6% |
| high single-digit | 7–9% |
| double-digit | 10–15% |
| low double-digit | 10–12% |
| low teens | 11–13% |
| mid-teens | 14–16% |
| high teens | 17–19% |
| low 70s | 71–73% (same bands for other levels: low 60s 61–63%, and so on) |
| mid 70s | 74–76% |
| high 70s | 77–79% |
| modest, modestly | 1–3% of the total the sentence is about |
| more than / over / greater than $X | floor of X. Not a coefficient. The total stays ≥ X. |
| about / approximately $X | not a coefficient. Build bottom-up and keep the total in a band. Start at ±5% of X. |
| record, strongest | not a growth rate. Use the run rate. |

## Relative phrases

Read these against **that line's** prior-year growth, not against the company total.

| Phrase | Starting default step |
|---|---|
| accelerating | prior growth +5 points |
| decelerating | prior growth −5 points |
| momentum continues, momentum continues to build | hold the prior growth |
| growing | do not invent a point. Take a number from somewhere else, or set a step and tag `[S]`. |
| shrinking | a decline. The size is `[S]` unless another phrase sizes it. |

Adjective strength changes the step. Starting points, still `[S]`: sharp ±8 points, gradual ±2, slight ±1. Context can make "sharp" mean something else; say what you used.

## Price and volume

If the line splits, mark each phrase:

- price: price, mix, rebates, gross-to-net
- volume: units, patients, procedures, customers, prescriptions

Forecast them separately and multiply. A one-time gross-to-net true-up is not a new price level unless the company says it persists.
